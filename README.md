# Dunia Box

Speak in Swahili or English and get a finished document back: invoice, receipt, quotation, memo, letter or meeting minutes, as a clean PDF.

Invoices can be paid onchain with Solana Pay, and every document can be verified on Solana.

## Structure

- `backend/` FastAPI service: transcription, speech to document, PDF generation
- `web/` Mobile-first React app
- `program/` Solana program (document registry)
- `docs/` Notes and benchmarks
- `samples/` Test audio (not committed)

## Status

Built for the Dev3pack Global Hackathon (27 to 29 November 2026).
